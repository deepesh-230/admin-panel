# Listings vs Service Providers

**Live listing path (use this):** `ServiceProvider` in the database, admin page `/service-provider/listing`, API `/api/v1/service-providers`.

**Legacy (do not add features):** `Listing` model, API `/api/v1/listings`, sample UI at `/sample` and `/sample2`. Those pages are experiments only.

When someone says “listing” in product work, they mean a **service provider**.
